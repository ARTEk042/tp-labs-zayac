Лабораторная работа 0. Вопросы о Git

1. Чем ветка отличается от копии папки?

Ветка — это указатель на коммит внутри одного репозитория: общая история, мгновенное переключение, встроенный merge. Копия папки — отдельные файлы на диске, дублирование и никакой связи с оригиналом.

2. Что будет с историей, если удалить файлы, но оставить .git?

История сохранится — она вся лежит в .git. Файлы вернутся командой git restore . или git reset --hard HEAD. Потеряется только незакоммиченное: правки и untracked-файлы.

3. Зачем Pull Request, если можно коммитить в main?

PR даёт ревью, автопроверки и обсуждение до попадания в main, а также защищает основную ветку от ошибок и push --force. Прямой push в main ок только для пет-проектов и срочных hotfix.
